**Tasks made joyful ✨**

My first full-stack project  

A minimal, aesthetic, and playful full-stack To-Do app built with **React**, **Node.js**, **Express**, and **MySQL**.  
Organize your tasks, mark them complete, and celebrate with fun confetti animations!

---

## 🌈 Features

- **Add, Edit, Delete Tasks** – Manage your daily tasks easily.  
- **Mark Tasks Completed** – Completed tasks fade and get a strikethrough.  
- **Confetti Celebration** – Fun confetti bursts when tasks are completed.  
- **Floating Add Button** – Smooth, interactive add button at bottom-right.  
- **Glassmorphic Task Cards** – Modern, playful UI with soft pastel colors.  
- **Responsive Design** – Works beautifully on desktop and mobile.  

---

## 🛠 Tech Stack

- **Frontend:** React, CSS  
- **Backend:** Node.js, Express  
- **Database:** MySQL  
- **Extras:** canvas-confetti for confetti celebration
